###Campus Navigator AR

A simple WebXR-based AR navigation prototype built with Babylon.js.
This project demonstrates how augmented reality can guide users to locations using 3D arrows in real space.

## Features

* WebXR AR experience
* Floor detection
* 3D arrows that show the way
* Paths to rooms like Room 101 Room 102 and Office
* A label that shows where you are going
* A reset button
  
## How It Works

1. Open the app in a browser that supports WebXR.
2. Choose a room, on the webpage.
3. Enter AR mode.
4. Move your device. Headset around to find the floor. A green circle will appear.
5. The path will show up automatically.. You can press the trigger to place it.
6. Just follow the arrows to get to where you're going.
   
## Technologies

* Babylon.js
* WebXR Device API
